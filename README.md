# 《集七宝》——七宝古镇烟火气互动 H5

面向闵行区“心动闵行·记录美好”网络作品征集活动（主题一：烟火闵行）创作的中英双语互动 H5 作品。

## 一、项目结构与核心功能

1. **完整 7 屏体验流程**：
   - **S0 加载页**：宣纸印章脉动、作品正副标题、加载进度条与百分比，顶部常驻中英切换与静音开关，点击“进入老街”手势解锁音频上下文。
   - **S1 封面页**：七宝老街暮色全景（WebP + JPEG 双格式兜底）、双语标题、开始寻宝入口。
   - **S2 传说引子**：支持按钮翻页、手指左右滑动翻页与“跳过传说”；卡 2 配备 7 件古宝矢量图标，点击任意图标即可查看民间传说来历与考据说明。
   - **S3 老街示意地图 (Hub)**：手绘风 SVG 示意图（角落标注“示意图 · 不按比例 / Schematic · Not to scale”），热点坐标直接由 `src/data/spots.json` 的百分比坐标驱动，支持首次进入手势引导提示与中英双语路牌切换。
   - **S4 地点详情抽屉**：支持点击遮罩、点击右上角关闭按钮或手指下滑（swipe down）关闭；内置双语简介、标签、待核实角标、人物心语扩展位、场景环境音试听，以及 **4 个专属微互动**（钟楼撞钟涟漪、手艺摊石板画糖画与游龙/锦鲤描红、羊肉与点心点击冒热气、皮影戏台左右拖拽）。
   - **S5 终章海报**：Canvas 2D 实时绘制 1080×1920“七宝集章卡”，7 个印章位均配中英双语地点名，底部随集章数（`<7` 或 `7/7`）自动切换结语，支持移动端长按保存图片。
   - **S6 信息与致谢**：双语交通指引、开放时间、游览贴士、7 处文化看点标签、参赛与版权声明，以及集章进度重置功能。
2. **零外部框架与全本地化**：Vite 打包，原生 JavaScript (ES Modules) + 原生 CSS 变量，无境外 CDN 请求，首屏与单张图片体积均严格控制在性能预算内（单张图片 ≤ 200 KB）。

## 二、运行与构建说明

### 1. 本地启动开发服务器
```bash
git clone https://github.com/manshushu/jiqibao.git
cd jiqibao
npm ci
npm run dev
```
启动后在浏览器访问 `http://localhost:5173/`（支持通过 `?lang=en` 参数直接以英文模式打开）。

### 2. 打包生产版本
```bash
npm run build
```
构建时 `qibao-audit-plugin` 会自动输出各地点 `verified` 核实状态、图片体积及音频占位检查报告。打包产物位于仓库根目录下的 `dist/`，为纯静态文件。仓库同时保留已构建的 `dist/`，可直接上传其内部全部文件至静态托管服务；首页 `index.html` 应位于部署目录最外层。请通过 HTTP/HTTPS 访问，不要直接双击 HTML。

### 3. 本地预览生产构建产物
```bash
npm run preview
```

## 三、素材替换与文案修改指南

### 1. 替换地点图片与现场音频
- **封面与地点图片**：位于 `public/assets/img/cover.webp`（含 `cover.jpg` 兜底）及 `public/assets/img/spots/{id}.webp`（含 `{id}.jpg` 兜底），建议宽度 ≤ 1080 px、单张体积 ≤ 200 KB。
- **音频素材**：将录制好的 `.mp3` 放入 `public/assets/audio/`（如 `bgm.mp3`、`bell-tower.mp3` 等）。当目录下未放置 `.mp3` 文件时，程序会自动使用 `src/audio.js` 中的 Web Audio API 合成各场景专属氛围音效。

### 2. 修改地点文案、人物话语与地图坐标
编辑 `src/data/spots.json`：
- `map.x` 与 `map.y`：地点在 SVG 地图上的百分比坐标（`0–100`），修改后地图热点位置自动更新。
- `name`、`summary`、`tags`：中英双语名称、简介（中文 40–70 字，英文 30–55 词）与标签数组。
- `quote`：人物采访原话（格式：`{ "zh": "...", "en": "...", "author": { "zh": "...", "en": "..." } }`），设为 `null` 时前端自动隐藏该模块。
- `verified`：设为 `false` 时卡片画面右上角显示“待核实 / To Verify”角标；核实无误后改为 `true` 即可隐藏。

### 3. 修改界面与传说文案
编辑 `src/data/i18n.json`，`zh` 与 `en` 键名一一对应，缺失英文键值时自动回退中文并在控制台提示。
